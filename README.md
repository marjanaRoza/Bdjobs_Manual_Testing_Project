# Bdjobs.com Manual Testing Project
Comprehensive manual testing portfolio for an online job marketplace


## 📌 Project Overview

**Application Under Test (AUT):** Bdjobs.com  
**Objective:** To perform manual testing of the Bdjobs.com web application and identify functional, validation, navigation, and usability issues.

## 🔍 Types of Testing Performed

- Functional Testing
- UI Testing
- Usability Testing
- Boundary Value Analysis
- Negative Testing
- Data Validation Testing
- Navigation Testing

## 🛠️ Tools Used

- Microsoft Excel – Test cases, bug reports, test execution & metrics
- Google Chrome – Web application testing
- GitHub – Project documentation & portfolio

## 📁 Project Structure

All testing deliverables are available in the Excel workbook:

**[📊 Bdjobs Manual Testing Deliverables](./Bdjobs_Manual_Testing_Deliverables.xlsx)**

The workbook contains:

- **Test Plan** – Testing objectives, scope, approach and planning
- **Mind Map** – Application features and testing areas
- **Test Scenarios** – High-level testing scenarios
- **Test Cases** – Detailed test cases with expected and actual results
- **Bug Report** – Identified defects with severity and priority
- **Test Case Report** – Test execution results
- **Test Metrics** – Testing performance and execution metrics

The testing identified issues related to:

- Employer Sign Up navigation
- Captcha validation
